# PizzaHut-Sales-Analysis
 1. Project Overview
The Pizza Sales Dashboard is an interactive Power BI report designed to analyze pizza sales performance, customer ordering behavior, and revenue trends. It helps businesses make data-driven decisions by providing actionable insights from sales data.

 2. Short Description / Purpose
This dashboard provides a comprehensive analysis of pizza sales, including total revenue, order trends, best-selling pizzas, and category performance. The objective is to identify sales patterns and improve business profitability through data visualization.

 3. Tech Stack
The dashboard was built using the following tools and technologies:

- 📊 Power BI Desktop
- 🔄 Power Query
- 📈 DAX (Data Analysis Expressions)
- 🗄️ SQL / Excel Dataset
- 📉 Interactive Visualizations

 4. Data Source
Pizza Sales Dataset
Includes order details, pizza categories, pizza sizes, quantities sold, revenue, and order dates.

 5. Features / Highlights

- 📈 Total Revenue, Total Orders, and Total Pizzas Sold KPIs
- 🍕 Best-Selling and Worst-Selling Pizza Analysis
- 📊 Category-wise Sales Performance
- 📏 Size-wise Sales Distribution
- 📅 Daily and Monthly Sales Trends
- 💰 Average Order Value Analysis
- 🏆 Top 5 Best-Selling Pizzas
- 📉 Bottom 5 Least-Selling Pizzas
- 🎯 Interactive Filters and Slicers for Dynamic Analysis
- 📌 Business Insights for Data-Driven Decision Making

  "In this Pizza Sales Dashboard, I created several key features to help analyze business performance.
  1) Total Revenue, Total Orders, and Total Pizzas Sold KPIs provide a quick overview of overall sales performance.
  2) Best-Selling and Worst-Selling Pizza Analysis helps identify the most and least popular products.
  3) Category-wise Sales Performance shows which pizza categories contribute the most to revenue.
  4) Size-wise Sales Distribution analyzes customer preferences for different pizza sizes.
  5) Daily and Monthly Sales Trends help track sales patterns and identify peak business periods.
  6) Average Order Value Analysis measures the average amount spent per order.
  7) Top 5 and Bottom 5 Pizza Analysis highlights the highest and lowest performing products.
  8) Interactive Filters and Slicers allow users to dynamically explore the data and generate insights.
  9) Overall, the dashboard helps management make data-driven decisions related to inventory, marketing, and sales strategy.
